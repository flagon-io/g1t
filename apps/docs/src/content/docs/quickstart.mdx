This page takes you from sign-up to a pull request your coding agent
opened and you merged. It takes a few minutes.

<Aside type="tip" title="Let an assistant do it">
  Give your AI assistant [g1t.sh/llms.txt](https://g1t.sh/llms.txt) and ask it to set you up. It gives you a link to open in your browser, where you sign up and
  approve it. It never sees your password.
</Aside>

<Steps>

1. **Sign up**

   [Sign up](https://g1t.sh/register) with an email address and a
   password, or with GitHub. Anyone can; no invite is needed. Confirm your
   email with the code g1t sends (or the link in the same email).

   Your account comes with a **workspace** of its own, named after your
   username. It holds your repositories and your channels. See
   [workspaces](/guides/workspaces/).

2. **Install the CLI and sign in**

   <Tabs syncKey="os">
     <TabItem label="macOS and Linux">```sh curl -fsSL https://g1t.sh/install | sh ```</TabItem>
     <TabItem label="Windows">```powershell irm https://g1t.sh/install.ps1 | iex ```</TabItem>
   </Tabs>

   ```sh
   g1t auth login --git
   ```

   `g1t` shows a code and opens your browser: check the code and approve.
   `--git` also sets git up to use the same sign-in for `g1t.sh`, so
   `git push` asks for nothing. `g1t auth status` shows who you are signed
   in as. See [the g1t CLI](/guides/cli/).

   <Aside title="Without the CLI">
     Git and the API also take an [access token](/guides/authentication/#access-tokens): create one in [Settings → Access
     tokens](https://g1t.sh/settings/tokens), and give it to git as the password, with your username.
   </Aside>

3. **Push a repository**

   From a git repository with at least one commit:

   ```sh
   g1t repo create my-project --source . --remote g1t
   ```

   This makes `<workspace>/my-project`, private, adds it as the remote
   `g1t` and pushes. Plain git works too: pushing to a repository that does
   not exist creates it, private.

   ```sh
   git remote add g1t https://g1t.sh/<workspace>/my-project.git
   git push -u g1t main
   ```

   **New** in the site's header makes one empty, or imports one from
   GitHub or any git host by its address.

   <Aside title="Coming from GitHub?">
     Rename `.github` to `.g1t` before you push, and your GitHub Actions workflows run on g1t, most without changes. Workflows are compute: on a free workspace,
     an owner checks a card once under **Settings → Billing and plans** to start a $5 trial, which is never charged for the check. See [GitHub
     Actions](/guides/actions/), [No card, no compute](/guides/usage-and-billing/#no-card-no-compute) and [what is not supported
     yet](/about/limitations/#actions-and-runners).
   </Aside>

4. **Open a work item**

   On **Work**, in the left rail, choose **New work item** and pick the
   repository as its target, or:

   ```sh
   g1t work new --title "Greeting should name the caller" --body "Take a name from the first argument."
   ```

   A [work item](/work/work-items/) belongs to the workspace; opened
   from the repository, it has the repository as its origin.

   Say what is wrong or wanted, and what done means if you know it. Your
   agent works from this text.

5. **Connect your coding agent**

   This exercise needs a coding client with local git and shell access. Chat apps
   can inspect and discuss the project through MCP without a local checkout.

   <AgentSetup />

   Approve in your browser when it asks. Then ask:

   > Work on work item 1 of the `<workspace>` workspace on g1t, in
   > `<workspace>/my-project`. Open a pull request for it and record your
   > session as you go.

   It opens a pull request, pushes its change, and your
   workflows run on it as on anyone's. See
   [Connect an AI client](/guides/bring-your-own-agent/).

   <Aside title="Or assign it to g1t">
     With an Anthropic key under the workspace's [**AI**](/guides/ai/) settings, **Assign to g1t** in the work item's sidebar starts a session on that account,
     as you, and its card shows in the work item's conversation. See [Assign g1t](/guides/sessions/#assign-g1t-or-ask-it-in-the-thread).
   </Aside>

6. **Review and merge**

   Open the pull request. **Files changed** shows what it did, and
   **Session** shows how: its prompts, reasoning and tool calls. Choose
   **Merge**, or turn on **auto-merge** to have it land once its required
   checks pass. The work item closes, recording which pull request landed
   it.

</Steps>

## Bring your team

Choose **Chat** in the app bar. Every workspace starts with `#general`, and
Chat is free on every plan. Adding people to a workspace comes with
[the g1t plan](/guides/usage-and-billing/#the-g1t-plan); on a free one,
[invite a friend](/guides/authentication/#invite-a-friend) to g1t instead,
or open a [public channel](/guides/chat/#public-channels) that anyone signed in to g1t can join. See
[Chat](/guides/chat/).
