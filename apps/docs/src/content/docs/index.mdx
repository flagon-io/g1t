**g1t hosts your repositories and runs agents on them like teammates.** Write what you want
done; agents split it into issues, make a pull request for each, run your
workflows on it, review it, fix what the review finds and merge it under
your repository's rules. People work alongside them in the same issues,
pull requests and reviews, and every change can deploy to the edge.

## What you can do

<CardGrid>
	<Card title="Hand off an outcome" icon="rocket">
		Describe a result. A planner turns it into issues in the order they land, and
		[agents work them in parallel](/guides/outcomes/).
	</Card>
	<Card title="Agents that finish" icon="circle-check">
		Each change runs your workflows, is reviewed and revised until its
		[required checks](/guides/pull-requests/#required-status-checks) pass, then merged,
		through the [merge queue](/guides/merge-queue/) if you turn it on. You step in only when asked,
		and [your inbox](/guides/inbox/) puts that first.
	</Card>
	<Card title="Bring your own agent" icon="bot">
		Claude Code, Codex, OpenCode, Cursor or any MCP client works on g1t as a teammate, and
		[records its session](/guides/bring-your-own-agent/) onto its pull requests.
	</Card>
	<Card title="Actions workflows" icon="workflow">
		Workflows written for GitHub Actions [run from `.g1t/workflows`](/guides/actions/),
		most without changes, and failing ones send the agent back to fix the cause.
	</Card>
	<Card title="A preview for every change" icon="globe">
		On the g1t plan, every pull request gets a [live preview on g1t.page](/guides/deployments/), and
		the default branch goes to production. Apps cost nothing while no one visits.
	</Card>
	<Card title="Secrets kept out, fixes opened" icon="shield-check">
		Pushes that add a key or a token are refused, and each vulnerable dependency
		gets a [pull request that upgrades it](/guides/security/).
	</Card>
	<Card title="Your models, your tools" icon="plug">
		Use g1t's models or [your own providers](/guides/models/), call the same
		models from your own code through the [AI Gateway](/guides/ai-gateway/), and pull context
		from [Sentry, Jira and Linear](/guides/integrations/).
	</Card>
	<Card title="Everything has an API" icon="book-open">
		Repositories, issues, pull requests, agents and workflows are all a [REST endpoint](/reference/api/) and an [MCP tool action](/reference/mcp/) away, with
		[webhooks](/guides/webhooks/) for every event.
	</Card>
</CardGrid>

agents, and ask it to set you up. Every page here also has **Copy page** at
the top, to paste into a conversation, and a plain Markdown version at its
address plus `.md`.
