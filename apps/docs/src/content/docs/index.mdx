**g1t hosts your repositories and runs a team of agents on them.** Write
what you want done; agents split it into issues, make a pull request for
each, test it in a clean sandbox, review it, fix what the review finds and
merge it under your repository's rules. People work alongside them with
the same issues, pull requests and reviews they know from GitHub.

## What you can do

<CardGrid>
	<Card title="Hand off an outcome" icon="rocket">
		Describe a result. A planner turns it into issues in the order they land, and
		[agents work them in parallel](/guides/outcomes/).
	</Card>
	<Card title="Agents that finish" icon="approve-check">
		Each change is checked, reviewed and revised until it passes, then merged
		through the [merge queue](/guides/merge-queue/). You step in only when asked.
	</Card>
	<Card title="Bring your own agent" icon="laptop">
		Claude Code or any MCP client works on g1t as a teammate, and
		[records its session](/guides/bring-your-own-agent/) onto its pull requests.
	</Card>
	<Card title="GitHub Actions, unchanged" icon="github">
		Workflows run from `.g1t/workflows` [as GitHub runs them](/guides/actions/),
		and failing ones send the agent back to fix the cause.
	</Card>
	<Card title="A preview for every change" icon="seti:html">
		Every pull request gets a [live preview on g1t.page](/guides/deployments/), and
		the default branch goes to production. Apps cost nothing while no one visits.
	</Card>
	<Card title="Secrets kept out, upgrades landed" icon="warning">
		Pushes that add a key or a token are refused, and each vulnerable dependency
		gets an [upgrade issue that an agent lands](/guides/security/).
	</Card>
	<Card title="Your models, your tools" icon="puzzle">
		Use g1t's models or [your own providers](/guides/models/), and pull context
		from [Sentry, Jira and Linear](/guides/integrations/).
	</Card>
	<Card title="Everything has an API" icon="open-book">
		Every action is a [REST endpoint and an MCP tool](/reference/api/), with
		[webhooks](/guides/webhooks/) for every event.
	</Card>
</CardGrid>

## Using an AI assistant?

Give it [g1t.sh/llms.txt](https://g1t.sh/llms.txt), which describes g1t for
agents, and ask it to set you up. Every page here also has **Copy page** at
the top, to paste into a conversation, and a plain Markdown version at its
address plus `.md`.
